# ImportPC Product Photos

Stable CDN for LEFI IMPEX product listings on eBay.

## Structure
- `photos/A1/` - warehouse position A-1 (TPLINK TL-SG1008D switch)
- `photos/A2/` - warehouse position A-2 (Samsung 2GB DDR3 ECC)
- `photos/A3/` - warehouse position A-3 (Nanya 256MB DDR2 SO-DIMM)
- `photos/A4/` - future

## URL pattern
`https://raw.githubusercontent.com/ClaudeLEFI/importpc-photos/main/photos/<zone>/<photo>.jpg`

Photos resized to max 1600 px JPEG q=85.
